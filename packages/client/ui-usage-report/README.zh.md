# @deepseek-ai/dsh-client-ui-usage-report

[English](README.md) | 中文

Web GUI 的跨会话 token 用量对话框：侧边栏底部设置按钮旁的小图标（`sidebar.footer.action` 槽位）打开一个模态框，把宿主端的 `usage.report` 折叠成模型占比环形图与每日日历热力图。

## 展示内容

- **范围选择** — 报告按最近 7 天或最近 30 天截取（默认 30 天）；更早的数据不计、不显示，也不会出现在日历里。
- **汇总条** — 所选范围内的计费 token 总量、天数与去重会话数。
- **模型占比环形图** — 选中当天的模型构成，SVG 环形图 + 图例（模型、计费总量、百分比）；悬停扇区或图例行显示具体数字。默认选中范围内最近一个有用量的一天；把范围收窄后，落在范围外的选中天会回退到该范围内最近的一天。
- **每日日历热力图** — 按所选范围内的月份分块，每块是一个完整的自然月日历（中间完全无用的月份跳过）；每天一个方块，填充深浅按当天计费 token 缩放；悬停方块显示该日日期与具体 token 数，点击方块可将环形图切换到该天。

对话框在打开时用浏览器本地时区偏移调用一次 `usage.report`，因此日边界与查看者的墙钟一致。它自己管理加载/空态/错误座位，报告到达前不渲染内容。文案支持中英文。

## 模型体验

无直接影响：该对话框是只读 RPC 消费者，不添加任何提示词、消息、schema、工具或模型调用。

## 组合

```yaml
- name: '@deepseek-ai/dsh-client-ui-usage-report'
- name: '@deepseek-ai/dsh-session-usage-report'
```

宿主插件通过 apiproxy 网关提供 `usage.report`；未挂载时对话框显示错误座位。
